# План SEO-развития: Спецтехника Минск

Текущий адрес: https://11alone11.github.io/Gruzoperevozki_ai/

---

## 0. С чего начать: честная картина

**Что уже есть и работает.** Lighthouse 100/100/100/100, валидная разметка, sitemap
с картинками, `llms.txt`, IndexNow, CSP, три размера картинок в AVIF. Это
**техническая гигиена**: она не двигает позиции вверх, но снимает барьеры,
из-за которых сайт мог бы не попасть в индекс или ранжироваться ниже.

**Что не работает.** Всё остальное. Одна страница на 780 слов не может
конкурировать с сайтами, у которых по 200–500 страниц под каждый запрос.
Сейчас у сайта ровно один URL и один кластер запросов — «аренда спецтехники в
Минске». Всё, что ищут иначе («уборка снега погрузчиком», «аренда Амкодор 332»,
«вывоз грунта самосвалом»), ведёт на ту же страницу и проигрывает конкурентам
с точным совпадением.

**Про `llms.txt`.** Сделали — и правильно, это дёшево. Но будьте реалистами:
исследования 2026 года не находят подтверждений, что Google или языковые
модели используют этот файл при формировании ответов
([Search Engine Land](https://searchengineland.com/does-llms-txt-matter-467740),
[разбор](https://securityboulevard.com/2026/10/llms-txt-is-the-meta-keywords-of-2026/)).
Он не вредит и стоит 3 КБ — пусть лежит. Но ставку делать не на него, а на
контент и структуру.

## 1. Главное, что упускается: в Беларуси ранжирует Яндекс

Это меняет приоритеты почти полностью. В Беларуси Яндекс занимает
существенно большую долю, чем Google, и его факторы отличаются:

|                        | Google                  | Яндекс                                          |
| ---------------------- | ----------------------- | ----------------------------------------------- |
| Поведенческие факторы  | умеренно                | **очень сильно**                                |
| Коммерческие факторы   | через разметку          | **напрямую: цены, доставка, оплата, реквизиты** |
| Справочник организации | Google Business Profile | **Яндекс Бизнес** (сильнее влияет)              |
| Аналитика              | GA4                     | **Яндекс.Метрика влияет на поведенческие**      |
| Быстрая индексация     | Search Console          | **Яндекс.Вебмастер + IndexNow**                 |

Практический вывод: то, что мы делали под Google (идеальный Lighthouse,
JSON-LD), — необходимо, но недостаточно. Для Яндекса нужны **коммерческие
факторы прямо на странице**: полный прайс, условия доставки, способы оплаты,
реквизиты, часы работы, живой контент. Сейчас из этого есть только цены.

## 2. Ограничения текущего сетапа (важно понимать до вложений)

| Ограничение          | Последствие                                                                                                                         |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Домен `github.io`    | Поддомен бесплатного хостинга. Google ранжирует нормально, Яндекс относится настороженно — на `github.io` много спама               |
| Выдуманные контакты  | Организация не верифицируется ни в Яндекс Бизнесе, ни в GBP. Карточки в картах не будет — а это главный источник локального трафика |
| Нет реального адреса | Локальная выдача (карты, «рядом со мной») закрыта                                                                                   |
| Один URL             | 1 кластер запросов из ~40 возможных                                                                                                 |

**Это не повод не делать.** Контент и структуру можно собрать сейчас — на
демо-данных видно, как страницы индексируются и по каким запросам начинают
показываться. Но полноценный тест ранжирования возможен только на своём
домене с реальными контактами.

## 3. Быстрый эффект: блоки на текущей странице

Это можно сделать без новых URL. Ожидаемый прирост — охват длинного хвоста и
время на странице (поведенческие для Яндекса).

### 3.1. Блок «Что мы делаем» — 8 услуг

Сейчас сайт продаёт **машины**, а люди ищут **задачу**. Это самый большой
пробел. Карточки по 2–3 предложения:

| Услуга                              | Под какие запросы                                   |
| ----------------------------------- | --------------------------------------------------- |
| Планировка и выравнивание участка   | планировка участка погрузчиком, выравнивание грунта |
| Уборка и вывоз снега                | уборка снега погрузчиком, расчистка снега Минск     |
| Погрузка и разгрузка                | погрузка сыпучих материалов, разгрузка фуры         |
| Вывоз грунта и строительного мусора | вывоз грунта самосвалом, вывоз мусора               |
| Рытьё котлованов и траншей          | рытьё котлована, разработка грунта                  |
| Доставка песка, щебня, гравия       | доставка песка самосвалом                           |
| Расчистка и снос                    | расчистка участка, уборка территории                |
| Аренда на длительный срок           | аренда спецтехники на месяц                         |

Каждая услуга → отдельный `Service` в разметке.

### 3.2. Блок «Районы выезда»

Очень сильный локальный сигнал и покрытие гео-хвоста.

- **Минск:** Центральный, Советский, Первомайский, Партизанский, Заводской,
  Ленинский, Октябрьский, Московский, Фрунзенский
- **Пригород:** Боровляны, Колодищи, Смолевичи, Фаниполь, Дзержинск, Логойск,
  Заславль, Мачулищи

На первом этапе — просто перечисление текстом (не ссылки на пустые страницы:
тонкие страницы-дубли вредят). Отдельные страницы под районы — только когда
для каждого будет уникальный текст.

### 3.3. Блок «Сколько стоит на самом деле»

Сейчас цена только за час. Люди ищут «на смену», «на сутки».

| Техника     | Час    | Смена 8 ч | Минимальный заказ |
| ----------- | ------ | --------- | ----------------- |
| Амкодор 332 | 80 BYN | 560 BYN   | 2 часа            |
| Амкодор 342 | 80 BYN | 560 BYN   | 2 часа            |
| МАЗ 5551    | 40 BYN | 280 BYN   | 2 часа            |

Плюс строчка «что входит в стоимость»: оператор, ГСМ, доставка до объекта.

### 3.4. Блок «Как мы работаем» — 4 шага

Звонок → уточнение задачи → подача техники → работа и закрывающие документы.
Снимает возражения, увеличивает конверсию, добавляет контент.

### 3.5. Блок «Документы и оплата»

Для юрлиц это решающий фактор:

- работа по договору, закрывающие документы, ЭСЧФ
- безнал и наличные
- оплата по факту или предоплата

### 3.6. Кейсы — 3–4 примера с цифрами

«Расчистили 800 м² на объекте в Боровлянах за 5 часов, Амкодор 342».
Формат «задача → техника → срок → результат». Работает и на людей, и на
поиск (уникальные текстовые фрагменты).

### 3.7. FAQ расширить с 5 до 12 вопросов

Добавить: оплата, документы, ГСМ, кто отвечает за поломку, нужен ли пропуск в
город, работа в выходные, погода, минимальный срок, доставка за МКАД.

### 3.8. Навигация по секциям

Внутренние ссылки с осмысленным анкором (не «подробнее», а «аренда
погрузчика Амкодор 332»). Помогает и краулингу, и распределению веса.

## 4. Главный рычаг: новые страницы

Одна страница — один кластер. Чтобы расти, нужны отдельные URL.

## 5. Разметка: что добавить

| Что                         | Зачем                                                     |
| --------------------------- | --------------------------------------------------------- |
| `Service` × 8               | понимание услуг, не только техники                        |
| `areaServed` расширить      | районы Минска и пригороды как `City`/`AdministrativeArea` |
| `Offer` со сменой           | `UnitPriceSpecification` не только на час, но и на день   |
| `openingHoursSpecification` | локальная выдача — но нужны **реальные** часы             |
| `Review`                    | только с настоящими отзывами. Выдуманные = риск санкций   |

Чего **не делать**: `aggregateRating` на самом себе, отзывы на скрытом
контенте, разметка того, чего нет на странице.

## 7. Как измерять эффект

1. **Яндекс.Вебмастер → «Поисковые запросы»** — по каким фразам сайт уже
   показывается. Через 2–4 недели после публикации контента смотреть рост.
2. **Google Search Console → «Эффективность»** — показы, клики, средняя позиция.
3. **Яндекс.Метрика** — поведенческие: глубина, время, отказы.
4. Раз в месяц — фиксировать позиции по ядру (40 запросов из раздела 3–4).

Ориентир: первые показы по длинному хвосту — 2–6 недель; устойчивые позиции по
среднечастотным — 3–6 месяцев. Быстрее в этой нише не бывает.

## 8. Порядок действий

**Этап 1 — контент на главной (1–2 дня).** Блоки из раздела 3. Ничего не
ломает, даёт материал для индексации сразу.

**Этап 2 — три страницы-услуги (2–3 дня).** Погрузчик, самосвал, уборка снега.
Это ядро коммерческого трафика.

**Этап 3 — гео и брендовые страницы (по мере сил).** Районы, модели техники.

**Этап 4 — переезд на домен + реальные контакты.** Без этого Яндекс Бизнес и
карты недоступны, а это половина локального трафика.

**Чего не делать никогда:** покупные ссылки, дорвеи, страницы-клоны под каждый
район с одинаковым текстом, ключи в `alt` картинок, скрытый текст.
